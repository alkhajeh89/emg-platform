# Executive Documentation: EMG Platform

This documentation is intended for leadership stakeholders, providing a
business-focused view of the Enterprise Memory Graph (EMG) Platform, its
strategic value, and its operational governance.

`EXECUTIVE_SUMMARY.md` is the canonical, ratified L1 Executive Authority.
Other files in this directory are supporting executive communication or L4
delivery material unless their own status and approving authority explicitly
state otherwise. Product scope remains governed exclusively by
`docs/product/EMG_PRODUCT_ARCHITECTURE_FREEZE.md`; architecture remains
governed exclusively by accepted ADRs within their stated scope.
