# Local Development Infrastructure

Local development is orchestrated using `docker-compose.yml`, which brings up necessary datastores (PostgreSQL, Redis, Neo4j, Qdrant) and the Identity provider.

Refer to the root [docker-compose.yml](../../docker-compose.yml) and [Makefile](../../Makefile) for orchestration commands (`make up`, `make down`).
