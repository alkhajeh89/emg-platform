# Frontend Sprints

## Purpose
This directory contains feature-level design and implementation specifications for specific development sprints.

## Scope
Sprint-specific frontend design documents, proposals, and reviews.

## Naming Conventions
- Sprint folders: `sprint-N`
- Design documents: `sprint-N-design.md`

## Folder Organization
```text
sprints/
└── sprint-N/
    └── sprint-N-design.md
```

## Ownership
Frontend Engineering Team, Product Team.

See [Sprint 10 Design](../../engineering/sprint-10-design.md) for the established template.
