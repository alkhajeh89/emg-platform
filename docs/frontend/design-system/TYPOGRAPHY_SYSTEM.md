# Typography System

## Purpose
Defines the typographic hierarchy for clear communication.

## Scope
All text elements.

## Design Philosophy
Typography must prioritize information density and clarity for high-stakes analysis.

## Business Context
Enables rapid data ingestion in decision intelligence scenarios.

## Principles
- **Reading Hierarchy:** Clear distinction between headers, body, and metadata.
- **AI Content Hierarchy:** Distinct styling for AI-generated vs. human-authored content.
- **Evidence Hierarchy:** Stylistic differentiation for citations.

## Accessibility Considerations
- Dynamic font scaling support.

## Internationalization
- Support for platform-defined locales and script-specific font requirements.

## Enterprise Guidelines
- Use hierarchical semantic styles.

## Usage Guidelines
- Standard header levels.
- AI attribution styles.

## Anti-Patterns
- Low-contrast light gray text for primary content.
