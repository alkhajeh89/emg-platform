# Breakpoints

## Purpose
Standardizes responsive design across the platform.

## Scope
All responsive behaviors.

## Design Philosophy
Desktop-first approach for high-fidelity decisioning; responsive adaptation for lower-fidelity surfaces.

## Business Context
Supports ADR-014 Section 12 (Desktop/Mobile Strategy).

## Principles
- **Responsive Philosophy:** Progressive enhancement.
- **Desktop-First Reasoning:** High-complexity workspaces require large surface area.
- **Tablet/Mobile Constraints:** Simplified interaction models.

## Accessibility Considerations
- Breakpoints respect user zoom settings.

## Internationalization
- RTL considerations in mobile layout adaptation.

## Enterprise Guidelines
- Breakpoint naming conventions.

## Usage Guidelines
- Standard breakpoint application in layout.

## Anti-Patterns
- Designing for a specific device, not for the intent/surface.
