# Iconography

## Purpose
Defines semantic, accessible iconography usage.

## Scope
All UI icons.

## Design Philosophy
Icons are semantic, not decorative.

## Business Context
Improves UI scanning and rapid cognition.

## Principles
- **Semantic Consistency:** Same icon for same action.
- **Accessibility:** Mandatory alt-text/labeling.
- **Classification Icons:** Standard markers for data sensitivity.

## Accessibility Considerations
- Icons require accessible labels/alt text.

## Internationalization
- Ensure icons are not culturally biased; mirror for RTL where appropriate.

## Enterprise Guidelines
- Icon style consistency.

## Usage Guidelines
- When to use icons (e.g., in Action Bars).

## Anti-Patterns
- Using icons without accessible labels.
