# Color System

## Purpose
Defines the semantic color language for the EMG™ platform.

## Scope
All UI color applications.

## Design Philosophy
Colors must be semantic, signaling state and classification rather than pure aesthetic choices.

## Business Context
Ensures consistent risk and status communication across the platform.

## Principles
- **Semantic Mapping:** Colors represent functional state.
- **Risk Indication:** Standardized color coding for confidence and risk.
- **Classification Compliance:** Color must not conflict with classification visual markers.

## Internationalization

## Enterprise Guidelines
- Use semantic tokens; avoid hardcoding.

## Usage Guidelines
- Status (Success, Warning, Danger, Info).
- AI Confidence levels.

## Anti-Patterns
- Using color as the only source of truth.
