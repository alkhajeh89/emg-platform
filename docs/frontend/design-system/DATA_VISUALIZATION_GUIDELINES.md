# Data Visualization Guidelines

## Purpose
Defines consistent data representation.

## Scope
All charts, graphs, and timelines.

## Business Context
Essential for decision intelligence (Module 10).

## Principles
- **Explainability:** Visuals must map to provenanced data.
- **Density:** Balance between clarity and amount of information.

## Enterprise Guidelines
- Standardized data representation charts.

## Accessibility
- Charts must provide accessible alternatives (data tables).

## Internationalization
- Date/number formatting.

## Usage Guidelines
- Standard chart types usage.

## Anti-Patterns
- Misleading visualizations (e.g., distorted scales).
