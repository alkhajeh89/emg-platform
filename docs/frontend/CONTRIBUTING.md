# Contributing to EMG™ Frontend

## Onboarding
1.  Follow the [Engineering Onboarding](../engineering/onboarding.md).
2.  Ensure local environment matches [Coding Standards](../engineering/coding-standards.md).

## Development Workflow
*   **BFF (Backend-for-Frontend)**: Always follow the BFF pattern as defined in [ADR-014](../architecture/EMG_ADR-014_Enterprise_Presentation_Architecture.md).
*   **Component Composition**: Utilize components from the [Design System](../enterprise-design/DESIGN_SYSTEM.md).

## Pull Requests
*   All changes must follow [Conventional Commits](../CONTRIBUTING.md).
*   Ensure all CI checks pass (`.github/workflows/ci.yml`).
