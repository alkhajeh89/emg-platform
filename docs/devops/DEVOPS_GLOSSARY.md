# DevOps Glossary

- **GitHub Actions**: Platform used for CI pipeline execution.
- **CI Pipeline**: Automated workflow for building and testing code on pull requests/pushes.
- **Linting**: Automated check for code style and potential errors using tools like `ruff` and `black`.
- **Testing**: Automated execution of unit tests using `pytest`.
- **Type-checking**: Automated verification of Python type hints using `mypy`.
- **Editable Install**: Installation method where package changes are reflected immediately in the environment, used in `tools/scripts/install-libs.sh` and `tools/scripts/install-services.sh`.
