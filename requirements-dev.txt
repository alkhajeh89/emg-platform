# EMG Platform — root development toolchain
# =========================================
# Single source of truth for the developer/CI tooling used across the whole
# monorepo (lint, format, type-check, test, build, audit, git hooks). Installed
# into the repository .venv by `make bootstrap` (tools/scripts/bootstrap.sh).
#
# This is DEV/CI TOOLING ONLY. Runtime dependencies of each package live in that
# package's own pyproject.toml and are installed editable by
# tools/scripts/install-libs.sh and install-services.sh — do NOT duplicate
# runtime deps here.
#
# Versioning policy
# -----------------
# This input file records supported ranges.  CI and bootstrap install the
# generated, hash-locked requirements-dev.lock for reproducibility.
#
# Range policy:
#   * The floors match the versions already declared in the packages' own
#     [project.optional-dependencies].dev tables (pytest>=8.0, pytest-asyncio
#     >=0.24, mypy>=1.10, ruff>=0.6, types-PyYAML>=6.0), so the root toolchain
#     can never resolve BELOW what a package expects and cause a split toolchain.
#   * Floors (not exact pins) keep the single-.venv install compatible with the
#     libraries' own `requires-python`/dependency ranges and avoid resolver
#     conflicts as packages evolve, while still guaranteeing the features the
#     repo relies on (ruff 0.6 rule set E/F/I/UP/B/SIM; pytest 8 import-modes).
#   * Security updates are adopted by deliberately regenerating and reviewing
#     requirements-dev.lock, rather than by resolving a different environment
#     on each installation.
